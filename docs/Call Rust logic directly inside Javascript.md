## How to Express Rust Logic in Zola

## **Client-Side WebAssembly (True Rust in the Browser)**

If your **Rust-LIB** contains complex algorithmic logic (e.g., text processing, calculations, cryptography) that needs to run interactively based on user input, compile it to **WebAssembly (WASM)**.

1. Use `wasm-pack` to compile your **Rust-LIB** into a WASM package targeting the browser (`wasm-pack build --target web`).  
2. Drop the compiled `.wasm` and `.js` glue files into Zola's `static/js/` directory.  
3. Call your native Rust functions directly inside a standard JavaScript script in your Zola template:

import init, { my\_rust\_lib\_function } from '/js/my\_rust\_lib.js';

async function run() {  
    await init();  
    const result \= my\_rust\_lib\_function("input data");  
    console.log("Calculated by Rust:", result);  
}  
run();

## A Zola website can include and run a WebAssembly (.wasm) binary

Because Zola generates a standard, static HTML / CSS / JavaScript website, it can do anything a regular modern website can do. Modern web browsers can download and execute .wasm files directly using standard browser JavaScript.

1. Zola copies your .wasm file into the final website folder.  
2. When a user visits your site, their web browser (Chrome, Safari, Firefox) downloads that .wasm file.  
3. A tiny bit of JavaScript on your page tells the browser: *"Hey, load this Rust binary into memory and run it right here in the browser."* 

**1\. Compile your Rust-LIB to WebAssembly**

Instead of building a normal desktop library, tell Rust to compile your code for the web using a tool called wasm-pack.

In your terminal, navigate to your **Rust-LIB** workspace and run:

bash  
wasm-pack build \--target web \--out-dir zola-site/static/wasm

*(This command tells Rust to compile your logic and output a .wasm file and a helper .js file directly into Zola's static/wasm/ directory.)*

**2\. Include the JavaScript in your Zola HTML Template**

In your Zola theme or layout file (e.g., templates/page.html), add a standard HTML \<script\> tag. This script fetches the compiled Rust code and starts it up:

html  
\<script type="module"\>  
    // 1\. Import the Javascript initializer generated by Rust  
    import init, { your\_rust\_function } from '/wasm/rust\_lib.js';

    async function start() {  
        // 2\. Tell the browser to load and compile the .wasm file  
        await init();

        // 3\. Call your Rust logic directly inside Javascript\!  
        const result \= your\_rust\_function("Hello from Zola HTML\!");  
        console.log(result);  
    }

    start();  
\</script\>

**3\. Run Zola**

When you run zola build or zola serve, Zola automatically moves everything in your static/ folder into the final public website. The browser handles the rest. 

* **True Rust performance:** The code running in your user's browser is your *exact* Rust code running at near-native speeds.
